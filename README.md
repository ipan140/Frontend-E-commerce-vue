# Vue E-Commerce Dashboard (TailAdmin Template)

This project is an **E-Commerce Dashboard and Frontend Interface** built using the **TailAdmin Vue Template**.
It is designed to manage and display e-commerce data such as products, orders, customers, and analytics through a modern admin dashboard.

The project is built with modern web technologies including **Vue 3**, **Vite**, and **Tailwind CSS**, providing a fast and scalable development environment.

---

## 🚀 Tech Stack

This project uses the following technologies:

* **Vue 3**
* **Vite**
* **Tailwind CSS**
* **TypeScript**
* **Pinia (State Management)**
* **Vue Router**
* **ApexCharts**
* **JSVectorMap**

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/ipan140/Frontend-E-commerce-vue.git
```

Move into the project folder:

```bash
cd Frontend-E-commerce-vue
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

## 🏗 Build for Production

```bash
npm run build
```
